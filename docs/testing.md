# 测试

```bash
invoice_cn_ce test                              # 控制台脚本
python -m pytest tests/ -v                  # 直接 pytest
ruff check src tests
mypy src/invoice_cn_ce
```

> 企业版相关用例（报关单解析、批量提取、电子承兑解析）带 `skipif` 标记：装了
> `invoice_cn_ee` **且**提供了有效许可证才会跑。公开 CI 只跑 lint + 类型检查
> + Docker 冒烟（真实票据样本与完整用例集在私有验证环境，不入公开仓库）；
> 企业版自身的用例在**企业版仓库**里单独运行。

## 样本从哪来

样本共 42 个（35 PDF + 5 XML + 2 OFD）。`samples/` 按票种子目录组织：

| 目录 | 票种 |
| --- | --- |
| `新电子发票-标准/` | 标准双栏电子发票（含京东 / 水费 / 通行费变体） |
| `新电子发票-旧格式/` | 旧格式电子发票 |
| `新电子发票-平台下载/` | 平台下载版电子发票 |
| `成品油合并代码/` | 合并代码 / 成品油 |
| `铁路电子客票/` | 铁路电子客票 |
| `航空运输电子客票/` | 航空运输电子客票行程单 |
| `中央非税收入统一票据/` | 中央非税收入统一票据 |
| `报关单/` | 海关出口货物报关单（企业版） |
| `全电发票-XML/` | 全电发票（数电票） |
| `全电发票-OFD/` | 全电发票（数电票） |

> **样本目录不在公开仓库里**（`.gitignore` 排除，避免真实票据外泄），归类表
> 由 `scripts/sync_samples_layout.py --regen-index` 在本地生成。

## 用例规模

开源版 **487** 条用例通过（88 skipped / 2 xfailed）；装上企业版包并提供有效
许可证后 **543** 条通过（32 skipped / 2 xfailed）；企业版仓库另有 **23** 条许可证与插件
专项测试。
